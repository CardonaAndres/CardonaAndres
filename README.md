## 👋 Sobre mí

Soy **Ingeniero de Software Full Stack** con enfoque en **Backend y Cloud/DevOps**, con más de 3 años de experiencia en el ecosistema **JavaScript/TypeScript** (Node.js, NestJS, React, Next.js) y conocimientos adicionales en **Python (FastAPI)** y **PHP (Laravel)**.

Manejo el ciclo de vida completo del software: desde el diseño de arquitecturas escalables y el modelado de bases de datos relacionales, hasta la implementación end-to-end del producto, la **integración de inteligencia artificial** para optimizar procesos y el **despliegue en infraestructura containerizada**.

- 🧱 Diseño y construyo **backends escalables** con NestJS y Node.js, desde la arquitectura hasta el despliegue
- 🔄 Implemento **CI/CD y despliegues blue-green** con Docker, GitHub Actions y Traefik/Nginx para lograr cero downtime
- 🤖 Integro **IA y automatización** para optimizar procesos de negocio reales
- 🛡️ Priorizo la **estabilidad en producción**: despliegues sin downtime, caché con Redis y colas asíncronas
- 📈 Opero y monitoreo sistemas en producción, corrigiendo incidentes críticos sin afectar el servicio
- 🎓 Ingeniería de Software · Corporación Universitaria Iberoamericana
